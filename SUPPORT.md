# Support

Use GitHub Issues for product support, reproducible bugs, and feature requests.

## Before opening an issue

1. Update to the latest release.
2. Retry the exact workflow once.
3. Record the screen, provider, and error message involved.
4. Remove secrets and client information from screenshots and logs.

## Include

- GEO SEO SuperApp version
- macOS version and Mac architecture
- steps to reproduce
- expected and actual behavior
- whether the issue affects one project or every project
- relevant provider status, without credentials

## Never include

- API keys or tokens
- passwords or private keys
- OAuth authorization codes
- non-public client URLs or content
- personally identifiable customer data

Security issues must follow [SECURITY.md](SECURITY.md) instead of being filed
publicly.

# Getting started

GEO SEO SuperApp is designed to be useful after two core connections, with
specialized services added only when a workflow needs them.

## 1. Install the app

Download the Apple silicon installer from the
[latest release](https://github.com/on-page-ai/geo-seo-superapp/releases/latest).
Open the disk image and move **GEO SEO SuperApp** to Applications.

The app is signed and notarized for macOS. If macOS reports that the installer
cannot be verified, stop and open a support issue rather than bypassing
Gatekeeper.

## 2. Complete the core setup

### AI setup

Sign in with the ChatGPT account you want the agent to use. The app checks that
the local Codex runtime is available and connected.

### On-Page.ai

Connect or create an On-Page.ai account. On-Page.ai supplies the SEO evidence
used for:

- Google entities and categorization
- competitive and cohort analysis
- information gain
- content depth and term coverage
- page performance and prioritized fixes

The SuperApp itself is free. On-Page.ai usage is metered through the plan and
credits on the account you connect.

## 3. Create projects

Use a project for each client, site, campaign, or internal property. Projects
keep conversations, reports, connected context, crawls, and recipe runs
organized without assuming that an agency works on only one site.

Agency and company details in Settings are used only for client-facing report
branding.

## 4. Add capabilities when needed

Open **Setup Center** from Settings or the macOS application menu.

| Connection | What it enables |
| --- | --- |
| Google Search Console | Performance, opportunities, URL inspection, and sitemaps |
| Bing Webmaster Tools | Bing performance, crawl, sitemap, and URL submissions |
| Browser tools | Visible QA and reviewed browser actions in Chrome, Edge, or Brave |
| Cloudflare | Hosted documents and personal indexer sites |
| Owned sites | WordPress and server-side publishing workflows |
| Social accounts | Drafting, publishing, and receipts for connected networks |
| MCP services | Optional third-party research and data tools |

Each provider retains its own account, plan, permissions, and limits.

## 5. Run the first workflow

1. Choose an objective or recipe.
2. Enter the keyword and page URL requested by that workflow.
3. Confirm the access mode.
4. Select **Run**.

The selected recipe is shown above the launcher so the action is clear before
it begins. Follow-up questions use the same project and conversation context.

## Getting help

Use the issue templates in this repository. Include:

- the SuperApp version
- macOS version
- the workflow and screen involved
- the exact error message
- whether the issue is repeatable

Remove client data and secrets before attaching logs or screenshots.
